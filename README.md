# html-components

[Telegram widget packs](telegram/README.md) – HTML-виджеты и текстовые подписи для ботов.

Библиотека из 60 готовых HTML-компонентов для страниц, отчётов, презентаций и слайдов. Страница или слайд собираются копированием готовых блоков, а не пишутся с нуля: это дешевле по токенам и выглядит одинаково везде.

Каждый компонент – один файл: комментарий-шапка, один `<style>` с уникальным префиксом классов `hc-<категория>-<имя>`, разметка. Два компонента на одной странице не конфликтуют. Данные внутри – демонстрационные.

Сайты (лендинги целиком) получат отдельный набор позже; секции лендинга в категории `landing` – только заготовки.

## Как пользоваться

1. Откройте `index.html` (одним файлом, без сервера) и выберите компонент. Либо найдите его в `CATALOG.json` по полю `use_for`.
2. Скопируйте файл из `components/<категория>/<имя>.html` целиком в свою страницу.
3. Замените данные (поля, которые нужно менять, перечислены в `data_slots` каталога и в шапке файла).
4. Не переименовывайте классы с префиксом `hc-`: по нему стили изолированы.

Каркас страницы – `templates/page.html` (подключены `tokens.css` и `fonts/fonts.css`, внутри вставлены три компонента). Шрифты необязательны: без них работает системный fallback.

## Правила

- Одна идея на блок: одна цифра, один график, одна мысль.
- Лайм `#D4FF00` – только маркер (выделение слова, главная цифра, активный шаг), не заливка больших областей.
- Без эмодзи. Тире – только «–». Кавычки – «ёлочки».
- Светлая тема: фон `#FAF8F2`, карточки `#FFFEFA`, граница `#D8D7C9`, текст `#24251E` / `#4F5147`; тёмная карточка `#15150F`.
- Шрифты: Inter Tight (текст), JetBrains Mono (подписи и цифры), с системными fallback.
- Каждый компонент проверен на ширине 1440 и 390 без горизонтальной прокрутки.

## Файлы

| Файл | Что это |
|---|---|
| `components/` | 60 компонентов по категориям |
| `index.html` | галерея всех компонентов, один самодостаточный файл |
| `CATALOG.json` | машинный каталог: id, категория, файл, название, где использовать, слоты данных, источник, лицензия |
| `tokens.css`, `fonts/` | общие токены и шрифты (woff2 + `fonts.css`) |
| `templates/page.html` | каркас страницы с тремя вставленными компонентами |
| `AGENTS.md` | инструкция для ИИ-агентов |
| `scripts/build.py` | пересобирает `CATALOG.json`, `index.html`, `templates/page.html`, списки в README и LICENSE |
| `scripts/check.sh` | проверки репозитория, печатает `OK` |

После правки или добавления компонента: `python3 scripts/build.py && scripts/check.sh`.

### KPI и метрики (6)

- `components/kpi/big-delta.html` – KPI – большое число с дельтой и прогресс-баром. Слайд или отчёт: главная цифра рынка за период и доля выделенной группы в ней.
- `components/kpi/metric-grid.html` – KPI – сетка из четырёх метрик с мини-графиками. Сводная полоса в отчёте или на слайде: четыре ключевые цифры в одну строку, первая карточка тёмная.
- `components/kpi/price-range.html` – KPI – ценовой диапазон и цена за результат. Слайд, отчёт или блок цен на лендинге: типичный ценовой диапазон рядом с ценой тарифа и тезисом «за результат, не за часы».
- `components/kpi/ratio.html` – KPI – гигантское соотношение 1 : 6 и две опорные цифры. Слайд или отчёт о размере рынка: крупное соотношение, семь делений и две опорные цифры для сравнения.
- `components/kpi/rings.html` – KPI – четыре кольца процентов. Слайд или отчёт об экономике сервиса: четыре процентные оценки в одном ряду; значение 50%+ выделено маркером.
- `components/kpi/stat-trio.html` – Три крупные цифры в ряд. Сводка из трёх ключевых чисел на слайде, в отчёте или на лендинге; вторая карточка тёмная, третья – «ноль» с маркером.

### Графики и данные (20)

- `components/data/area-cumulative.html` – Area chart – накопительный итог по месяцам. Слайд или раздел отчёта, где одним графиком нужно показать, как за полгода накопилась сумма по нескольким раундам финансирования; подходит для любой накопительной метрики по месяцам.
- `components/data/bar-horizontal.html` – Горизонтальные столбики. Сравнение значений по категориям с подписями; нулевая категория остаётся на виду с маркером.
- `components/data/bar-range-markets.html` – Range bar – диапазоны оценок рынков. Слайд или раздел отчёта, где нужно сравнить размер рынков, когда у каждого рынка вилка оценок, а не одно число; подходит для любых диапазонов «от – до».
- `components/data/bar-stacked-months.html` – Stacked bar – суммы по месяцам и нишам. Слайд или раздел отчёта с помесячной картиной, где виден всплеск в одном месяце и пустой месяц; каждая стопка – ниши, сверху сумма за месяц.
- `components/data/bar-vertical.html` – Вертикальные столбики с выводом. Сравнение двух-четырёх величин (например, 1 к 6) со вторым блоком текста справа.

- `components/data/bullet-margin.html` – Bullet chart – маржа и доля софта против метки. Слайд или раздел отчёта, где нужно показать факт против целевой метки (30% против 50%) и вторую строку с долей в расходах; наглядно видно, где показатель не дотягивает до метки.
- `components/data/donut-center.html` – Кольцо с числом в центре. Доля главного сегмента от целого с короткой подписью справа; подходит для слайда и блока отчёта.
- `components/data/funnel.html` – Воронка в масштабе. Сужение выборки по шагам: от общего числа до итога; ширина строки пропорциональна значению.
- `components/data/gauge-margin.html` – Gauge – маржа 30% против 50%+. Слайд или раздел отчёта, где одним жестом нужно показать разрыв: обычная сервисная фирма упирается в 30% маржи, целевая метка – 50% и выше.

## English (short)

A library of 60 copy-paste HTML components (KPI, charts, tables, diagrams, slides, landing sections) for pages, reports and slide decks. Each component is a single self-contained file: a header comment, one `<style>` scoped by a unique `hc-` class prefix, and the markup, so several components can live on one page. Open `index.html` to browse, pick a file from `components/`, copy it into your page and replace the demo data. `CATALOG.json` is the machine-readable index; `AGENTS.md` tells AI agents how to use and extend the library. Design rules: one idea per block, the lime accent only as a marker, no emoji. Code is MIT; layouts are inspired by components on 21st.dev (see `LICENSE`).
